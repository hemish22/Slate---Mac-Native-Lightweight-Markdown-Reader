## LinkedIn

I built Slate, a lightweight Markdown reader and editor for macOS.

The idea was simple: open a .md file from Finder, read it comfortably, and edit it in the same app.

Slate has three views:
• Editor for working with the Markdown source
• Preview for reading the rendered document
• Split for writing with a live preview beside it

I built it with Swift, AppKit, and the system WebKit preview. It also includes syntax colors, line numbers, autosave for saved files, an outline, synchronized scrolling, and a dark theme.

No account or backend. Your document stays a plain Markdown file on your Mac.

The source, build instructions, and tests are on GitHub:
https://github.com/hemish22/Slate---Mac-Native-Lightweight-Markdown-Reader

If you use Markdown on a Mac, I'd love to hear what would make this useful in your daily workflow.
