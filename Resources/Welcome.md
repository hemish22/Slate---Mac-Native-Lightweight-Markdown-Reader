# Welcome to Slate

A quiet place to read and edit Markdown. Native to your Mac, with a live preview that keeps up with your thoughts.

## One document, three ways to work

Choose a view in the toolbar, or use a shortcut:

| View | Shortcut | Best for |
| --- | --- | --- |
| Editor | ⌘1 | Focused writing |
| Preview | ⌘2 | Comfortable reading |
| Split | ⌘3 | Writing and reading together |

Drag the divider to give either pane more room. The **link button** keeps both panes scrolling together.

## Your files, right where they belong

Use **⌘O** to open a file and **⌘S** to save. Existing files save automatically as you work. New documents ask for a location when you first save or close them.

Open a Markdown file from Finder using **Open With → Slate**. To make Slate your default, select a `.md` file in Finder, choose **Get Info → Open with → Slate → Change All**.

## A few things to try

- Write **bold text**, *a little emphasis*, or `inline code`.
- Add a [link](https://commonmark.org) or a local image: `![Description](images/photo.png)`.
- Use the outline button to jump between headings.
- Press **⌘F** to find text, or **⌘+** and **⌘−** to adjust the size.
- Undo an edit with **⌘Z**. Use **⇧⌘S** to save a copy elsewhere.

> The preview updates as you type. Your document stays a plain Markdown file.
